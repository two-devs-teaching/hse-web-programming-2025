# Задание 4. React

**Задание:** переписать свой веб-проект на React.

**Критерии выполненного задания:**

* Проект написан польностью на React (то есть нет прямых обращений к DOM, всё реализовано инструментами библиотеки)
* Код разбит на компоненты, компоненты вынесены в отдельные файлы / директории
* В коде использованы модульные стили
* В коде использованы хуки (как минимум, useState для сохранения внутреннего состояния)

p.s. В качестве бойлерплейта (и по совместительству сборщика) можно использовать [Vite](https://vite.dev/guide/#scaffolding-your-first-vite-project)
